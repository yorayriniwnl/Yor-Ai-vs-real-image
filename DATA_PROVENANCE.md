# Dataset provenance register

This repository intentionally does **not** infer or invent provenance for image files. The current dataset is useful for reproducing the bounded experiment, but redistribution rights and origin records are incomplete.

## Release status

- **Experiment reproducibility:** available from the committed dataset snapshot.
- **Provenance completeness:** **INCOMPLETE**.
- **Redistribution clearance:** **NOT ESTABLISHED** for the dataset as a whole.
- **Production/general-purpose training use:** **NOT CLAIMED**.

Until every source family below has a verified origin and usage basis, treat the dataset as a research snapshot for repository-local evaluation rather than a cleared public benchmark.

## Provenance fields required for every source family

| Field | Required value |
| --- | --- |
| Origin | Creator, capture source, generator, dataset, or acquisition channel |
| Acquisition date | Date or bounded period when the file was obtained/generated |
| Rights basis | Owned capture, generated by project author, explicit license, permission, or other documented basis |
| Redistribution | Allowed / not allowed / unknown |
| Transformations | Resize, compression, watermarking, screenshotting, conversion, or other preprocessing |
| Deduplication | Method used to detect duplicate or near-duplicate samples |
| Notes | Any ambiguity or limitation relevant to use |

## Do not infer provenance from filenames

A filename can suggest a generator or capture device, but it does not prove ownership, permission, licensing, or the identity of the creator. Future updates should attach source records or a machine-readable manifest rather than relying on filenames.

## Recommended machine-readable follow-up

When provenance is known, add a manifest such as `dataset/provenance.csv` with at least:

```text
path,source_family,origin,acquired_at,rights_basis,redistribution,transformations,deduplication,notes
```

Do not fill unknown values with guesses. Use `UNKNOWN` until verified.

## Evaluation boundary

The current reported image-classification results remain dataset-specific. Completing provenance does not by itself establish robustness to new image generators, camera pipelines, compression, screenshots, edits, social-media transforms, or adversarial examples.
